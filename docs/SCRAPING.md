# Сбор цен: что известно и с чего начинать автоматизацию

Машиночитаемая часть — в `data/providers.json` (каналы и их особенности) и
`data/sources.json` (что откуда бралось по каждому объекту, со статусом и уровнем доверия).
Этот файл объясняет, как этим пользоваться.

## Как читать sources.json

Каждый объект — список источников. У источника есть `provider`, `type` (что он даёт),
`fetch` (`static` — хватит HTTP-запроса, `browser` — нужен настоящий браузер),
`status` и `confidence`.

Порядок работы для скрапера:

1. Взять источники с `type: "price"`, отсортировать: сначала `provider: "self"` со
   `status: "ok"` — это опубликованный прайс, он не зависит от дат и не устаревает за неделю.
2. Если своего прайса нет — идти в OTA (`booking.com`, `slowhop`, `nocowanie.pl`,
   `google_hotels`) с фиксированными пробными датами.
3. Всё, что помечено `confidence: "low"` или `status: "unverified"`, проверять в первую
   очередь: эти значения не сняты со страницы напрямую.

Раскладка по состоянию на сентябрь 2026 — 12 объектов:

| Способ получить цену | Объекты |
|---|---|
| Свой прайс на сайте (лучший случай) | Dwór Sanna, Turnau, Chronów, Mierzęcin |
| Только OTA | Maria Anna, Mała Wieś, Sztukówka, Jerzmanice, Poziom 511 |
| Цены только по запросу | Witaj Słońce |
| Нужен клик по календарю | Dwie Granice |
| Из поисковой выдачи, требует проверки | Płochockich |

## Пробные даты

Цены на OTA бессмысленны без дат. Текущий срез снят на **9–11 октября 2026, 2 гостя,
1 номер, PLN** (`meta.price_probe` в sources.json). Для сопоставимости замеров держите
одну и ту же схему, например «ближайшая пятница через месяц, 2 ночи, 2 гостя», и
записывайте фактические даты рядом со значением.

Нормализация: `price_per_night = total / nights`. Отдельно фиксируйте, входит ли завтрак —
на Booking это подпись «Śniadanie wliczone w cenę» у тарифа.

## Booking.com — рабочая схема

Единственный надёжный путь — прямой URL отеля в браузере:

```
https://www.booking.com/hotel/pl/{slug}.pl.html
  ?checkin=2026-10-09&checkout=2026-10-11
  &group_adults=2&no_rooms=1&group_children=0&selected_currency=PLN
```

Известные slug: `winnica-maria-anna-wyzne1`, `winnica-sztukowka`, `dwor-sanna`,
`palac-mala-wies`, `paaac-mierzacin-wellnes-amp-wine-resort`.
Для Poziom 511 slug подобрать не удалось — там берём Google Hotels.

Что важно знать:

- **HTTP-фетч не работает.** Страница возвращается пустой, цены рисует скрипт.
- **Поиск по названию бесполезен.** `?ss=Poziom+511+Podzamcze` выбрасывает на главную
  с `errorc_searchstring_not_found`.
- **Прямой URL может редиректить** на выдачу по населённому пункту. Так вышло с Maria Anna:
  вместо карточки отеля открылась выдача по Wyżne. Это не ошибка — там оказались сразу
  **четыре листинга одного хозяйства** (отель, домики, вилла, «Winne Tarasy»), и цены надо
  собирать со всех.
- **Дат может не быть в наличии.** Тогда появляется блок «Alternatywne terminy» с карточками
  «2 noce · Od X zł» по соседним датам — это нижняя граница, помечайте её как таковую.
- **Неверный slug молча отдаёт пустую страницу.** Проверяйте, что заголовок вкладки содержит
  имя объекта.

Где в разметке искать сумму:

| Ситуация | Якорь |
|---|---|
| Даты свободны | таблица «Typ pokoju / Liczba gości / Cena» |
| Дат нет | блок «Alternatywne terminy», карточки «{n} noce · Od X zł» |
| Страница выдачи | в карточке «{n} noce, {adults} dorosłych», ниже сумма; при скидке две цены — старая и текущая |

Суммы уже включают налоги и сборы («Zawiera opłaty i podatki»).

## Остальные каналы

**Google Hotels** — `https://www.google.com/travel/search?q={name}&currency=PLN`.
Запасной вариант, когда slug на Booking неизвестен. Даёт крупную плашку «X PLN» и список
офферов от провайдеров. Даты Google подставляет свои — либо задавайте явно, либо записывайте,
на какие даты получен замер (для Poziom 511 сохранён замер на 6–7 декабря).

**Slowhop** — `https://slowhop.com/pl/miejsca/{id}-{slug}.html`. Известные id: Jerzmanice 3378,
Sztukówka 3165. Страницы длинные, при статическом фетче контент обрезается — читать браузером.
Формат цены обычно «X zł за dobę do 2 osób, każda kolejna osoba +Y zł».

**Nocowanie.pl** — `https://www.nocowanie.pl/rezerwuj/{id}-{slug}/`. Dwie Granice: id 1505571.
Без дат цен нет вообще; параметров дат в URL найти не удалось, нужен клик по календарю.
В названии листинга опечатка: «Dwe Granice».

**Сайты объектов.** Обычно статические и парсятся простым запросом. Два исключения:
Witaj Słońce закрыт age-gate («Czy masz ukończone 18 lat?» → кнопка «Tak») и рендерит текст
скриптом, а winnicajerzmanice.pl лежит и отдаёт заглушку хостинга — проверяйте при каждом
прогоне, не подняли ли его.

## Ограничения окружения

Собиралось через MCP-браузер claude-in-chrome. Что в нём не заработало:

- `localhost` и `file://` не открываются — отладить страницу локально не выйдет, только
  вручную в обычном браузере
- синтетические клики не проходят внутрь iframe артефакта на claude.ai (не срабатывают даже
  кнопки зума), поэтому интерактив проверяется только руками
- `poziom511.obvio.app` отдал error page

Для настоящей автоматизации это всё неважно — там будет Playwright или аналог, и ограничения
снимутся. Но сами особенности сайтов (age-gate, JS-рендеринг, календари) останутся.

## Минимальный план скрапера

1. Читаем `data/sources.json`, берём источники с `type: "price"`.
2. `provider: "self"` со `status: "ok"` — HTTP-запрос и парсинг прайса по месту.
3. Остальные — Playwright: открыть URL с подставленными датами, дождаться блока цен,
   снять сумму по якорям из таблицы выше.
4. Нормализовать к цене за ночь, приписать `checkin`/`checkout`/`adults`/`breakfast`.
5. Записать в `data/prices.{дата}.json`, сравнить с предыдущим срезом, обновить поля
   `price` и `pnote` в `PLACES` внутри HTML.
6. Пересобрать `data/places.json` командой из README и переопубликовать артефакт по
   существующему URL.

Файла `data/prices.*.json` пока нет — первый срез живёт прямо в полях `price`/`pnote`
объектов и продублирован в `docs/SOURCES.md`.
